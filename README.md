# Krieger Advocacia Especializada - Landing Page

Landing page profissional para o escritório de advocacia Krieger Advocacia Especializada, desenvolvida com HTML, CSS e JavaScript puro, utilizando Tailwind CSS para estilização.

## 📋 Sobre o Projeto

Este projeto é uma landing page moderna e responsiva que apresenta os serviços jurídicos oferecidos pelo escritório Krieger Advocacia Especializada. A página inclui informações sobre áreas de atuação, equipe jurídica, processo de atendimento, depoimentos de clientes e uma seção de perguntas frequentes.

## ✨ Funcionalidades

- **Design Responsivo**: Totalmente adaptável para dispositivos móveis, tablets e desktops
- **Navegação Suave**: Scroll suave entre seções da página
- **Formulário de Contato**: Formulário integrado na seção hero para captação de leads
- **Slider de Depoimentos**: Carrossel interativo com depoimentos de clientes
- **FAQ Interativo**: Acordeão com animações suaves para perguntas frequentes
- **Seções Informativas**:
  - Hero com formulário de contato
  - Áreas de atuação (6 especialidades)
  - Consultoria jurídica estratégica
  - Processo de atendimento (4 etapas)
  - Equipe jurídica (3 profissionais)
  - Depoimentos de clientes
  - FAQ

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica da página
- **CSS3**: Estilização customizada e animações
- **Tailwind CSS**: Framework CSS utilitário (via CDN)
- **JavaScript (Vanilla)**: Interatividade e funcionalidades dinâmicas
- **Google Fonts**: Fonte Inter para tipografia

## 🚀 Como Usar

### Visualização Local

1. Clone ou baixe o repositório
2. Abra o arquivo `index.html` em um navegador web moderno
3. Não é necessário instalar dependências, pois o Tailwind CSS é carregado via CDN

### Hospedagem

O projeto pode ser hospedado em qualquer serviço de hospedagem estática:
- GitHub Pages
- Netlify
- Vercel
- AWS S3
- Qualquer servidor web estático

## 📱 Seções da Página

### 1. Top Bar
Barra superior com informações de contato (email, telefone, WhatsApp) e links para redes sociais.

### 2. Navegação
Menu de navegação com links para as principais seções:
- Áreas de atuação
- Equipe jurídica
- Atendimento
- Depoimentos
- FAQ

### 3. Hero Section
Seção principal com título impactante e formulário de contato integrado.

- Direito Previdenciário

1. Triagem
2. Estratégia
3. Proposta
4. Acompanhamento

Apresentação dos 3 profissionais:
- Alcione Krieger

- Alan Batista

### 8. Depoimentos
Slider com depoimentos de clientes satisfeitos.

### 9. FAQ
Perguntas frequentes com acordeão interativo.

### 10. Footer
Rodapé com informações de contato, endereço e links legais.
